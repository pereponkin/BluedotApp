# Матрица ручной приёмки

Этот документ фиксирует ручные проверки автономных пакетов. Автоматические тесты и smoke-тесты CI не заменяют вход в настоящий аккаунт Blue Dot Sessions.

## Обязательные сценарии

В каждой строке нужно проверить: первый запуск, загрузку Firefox при необходимости, вход, сохранение API-ключа, поиск, историю запросов, масштабирование панели, воспроизведение, скачивание и открытие файла, повторный запуск, смену браузера после перезапуска и блокировку второго экземпляра.

| Платформа | Браузер | Статус |
|---|---|---|
| Windows x64 | Firefox | ожидает проверки финального пакета |
| Windows x64 | Google Chrome | ожидает проверки финального пакета |
| macOS Intel | Firefox | ожидает проверки на Intel Mac |
| macOS Intel | Google Chrome | ожидает проверки на Intel Mac |
| macOS Apple Silicon | Firefox | ожидает проверки на Apple Silicon Mac |
| macOS Apple Silicon | Google Chrome | ожидает проверки на Apple Silicon Mac |

Перед выпуском замените статус каждой строки на дату, версию пакета и имя проверившего. Невыполненная строка означает, что соответствующая комбинация ещё не прошла ручную приёмку.
